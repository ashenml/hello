What Are Miller Indices?

In crystallography, Miller Indices form a standardized vector notation system used to describe the orientation of crystal planes and crystallographic directions within a unit cell lattice.

How to Calculate

The Four Essential Notations

(h k l)

Specific Plane

Enclosed in standard parentheses with no commas. Represents a single specific parallel set of lattice planes.

Example: (1 1 0), (2 0 0)
{h k l}

Family of Planes

Enclosed in curly braces. Represents all symmetry-equivalent planes in the crystal system.

{100} = (100), (010), (001)...
[u v w]

Specific Direction

Enclosed in square brackets. Represents a directional vector pointing from origin to lattice point $(u,v,w)$.

Example: [1 1 1], [0 1 0]
⟨u v w⟩

Family of Directions

Enclosed in angle brackets. Groups all crystallographically equivalent vector directions.

⟨100⟩ = [100], [100], [010]...

4 Steps to Determine Miller Indices $(h k l)$

Follow this universal recipe for any crystal plane

1

Identify Intercepts

Find where the plane intersects coordinate axes $x, y, z$ in terms of lattice constants $a, b, c$.

e.g., $1a, 2b, \infty c$
2

Take Reciprocals

Calculate the reciprocal of each fractional intercept ($1/x$, $1/y$, $1/z$). Parallel axes ($\infty$) become $0$.

$\frac{1}{1}, \frac{1}{2}, \frac{1}{\infty} \rightarrow 1, \frac{1}{2}, 0$
3

Clear Fractions

Multiply all values by the Least Common Multiple (LCM) to reduce them to the smallest set of integers.

$(1, 1/2, 0) \times 2 \rightarrow 2, 1, 0$
4

Enclose Notation

Enclose in parentheses with NO commas. Negative integers receive an overhead bar (e.g., $\bar{1}$).

Final Result: (2 1 0)

Interplanar Spacing ($d_{hkl}$)

Distance between adjacent parallel planes

For a cubic crystal system with lattice constant $a$, the perpendicular distance $d_{hkl}$ between adjacent parallel planes $(hkl)$ is given by Bragg's Law foundation:

dhkl = a / √(h² + k² + l²)

* Higher index planes (e.g. 311) are packed closer together than low index planes (e.g. 100).

Hexagonal Miller-Bravais $(h k i l)$

4-Index notation for Hexagonal Systems

Hexagonal crystal systems use four axes ($a_1, a_2, a_3$ in the basal plane at $120^\circ$, plus vertical $c$-axis). This preserves symmetry relations.

h + k + i = 0 | i = -(h + k)

Example: A plane with $h=1, k=1$ automatically has $i = -2$, written as (1 1 2 0).
